Bitcoin Summer Burn 2026 — a Nostr-based revival of the funjunkie CD swap event. Built on MKStack (React/Vite/Nostr). RSVP, feed, forum, gallery, FAQ, and CD listings (NIP-99) are implemented.

**Why:** Community CD swap event run on Nostr for privacy/decentralisation.

**How to apply:** When suggesting features, keep Nostr-native patterns (events, zaps, DMs) and the Bitcoin/privacy ethos of the project.

## Planned: npub profile pages (`/[npub]`)
The `NIP19Page.tsx` npub route currently shows a placeholder. Planned to become a seller profile page showing:
- Their CD listing
- Stats and reviews (e.g. swap feedback/ratings)

Do not implement until the user asks.
